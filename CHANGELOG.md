# Paxels & AIOTs v1.0.3

This update synchronizes every standalone Paxel and AIOT with UtilityCraft and improves their shared tool behavior.

## HIGHLIGHTS

- Synchronized all seven Paxels and AIOTs with their UtilityCraft counterparts.
- Added path creation, snow clearing and 3x3 harvesting to AIOTs.
- Updated tool stats, digging behavior, repairs and translations.
- Fixed legacy texture and durability implementation issues.

## CHANGED

- Synchronized all seven standalone Paxels and AIOTs with their UtilityCraft counterparts.
- Updated tool damage, durability, tags, repair values, and digging behavior.
- Updated item names and added the translations available in UtilityCraft.

## ADDED

- Added the UtilityCraft AIOT shovel behavior, including path creation and snow clearing.
- Added 3x3 harvesting support to AIOTs.

## FIXED

- Fixed wooden and golden texture atlas identifiers.
- Replaced the legacy component registry and durability implementation.
